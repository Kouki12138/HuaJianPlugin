# 花键参数生成器（AutoCAD 2024 插件）

在 AutoCAD 2024 中输入花键参数、拾取圆心，自动生成渐开线花键轮廓（外花键，支持 30°、14.5° 等常用压力角）。

## 功能特性

- 对话框输入花键参数（径节/模数、齿数、压力角、分度圆/齿顶圆/齿根圆直径、分度圆弧齿厚、渐开线起始圆、齿根圆角等），带公差与精度等级注释；
- 支持按“渐开线起始圆 + 齿根圆弧”精确构造齿根：齿槽底部为一段半径 R 的圆弧，同时与相邻两条渐开线齿面相切，圆弧最低点落在小径上；
- 拾取圆心一键生成完整花键轮廓，自动附带分度圆参考线、中心十字线；
- 两种轮廓输出方式：整体多段线 / 每齿独立的样条曲线（齿廓为 SPLINE，齿顶齿根为真圆弧）；
- 提供一键安装 EXE，自动部署到 AutoCAD 自动加载目录；
- 源码公开，可用 `build.cmd` 自行编译。

## 安装（二选一）

### 方式零：一键安装（EXE，推荐）
双击 `HuaJianPluginSetup.exe`，程序会自动把插件安装到 AutoCAD 的自动加载目录
（`%APPDATA%\Autodesk\ApplicationPlugins`）。
安装完成后重启 AutoCAD，输入 `HUAJIAN` 即可使用。

### 方式一：自动加载（推荐）
把 `HuaJianPlugin.bundle` 整个文件夹复制到：

```
%APPDATA%\Autodesk\ApplicationPlugins
```

然后重启 AutoCAD。命令 `HUAJIAN` 自动可用。

### 方式二：手动加载
在 AutoCAD 中执行：

```
APPLOAD
```

在文件类型中选择“.NET 程序集”，加载 `HuaJianPlugin.dll`（或在 APPLOAD 中点击“内容”，把该 DLL 加入启动组，以后自动加载）。

## 使用

1. 命令行输入 `HUAJIAN` 回车；
2. 在弹出的对话框中输入花键参数（默认已填好 65 齿那组数值：m=2.54、Z=65、α=14.5°、分度圆 Φ165.1）；
3. 在“轮廓输出”下拉中选择输出方式：
   - **整体多段线**（默认）：整个花键为一个闭合多段线对象，齿廓由密集小线段逼近；
   - **样条曲线**：每侧齿廓为一条 SPLINE 样条，齿顶/齿根为真圆弧，每齿独立对象，齿面无折角；
4. 点【确定】；
5. 在图形中拾取花键中心点，程序自动生成：
   - 完整花键轮廓（含齿顶圆弧、渐开线齿廓、齿根圆角与齿根圆弧）；
   - 分度圆参考线（CENTER 线型）；
   - 中心十字线；
   - 可选的参数注释文字（含公差）。

## 参数说明

- 径节 (DP) 与模数自动换算（模数 = 25.4 / 径节）；模数或齿数改变时分度圆直径自动按 模数×齿数 更新。
- 齿顶/齿根直径、分度圆弧齿厚为**名义值**，用于生成轮廓；旁边填写的公差只进入注释文字，不参与轮廓几何（公差属检验要求）。
- 当前版本支持外花键（齿根圆 < 分度圆 < 齿顶圆），要求齿根圆直径 ≥ 基圆直径（基圆 = 分度圆 × cos 压力角），否则提示不支持（根切花键）。
- “渐开线起始圆”填 0 表示不启用该功能（从齿根圆一直画渐开线）；填写直径后，渐开线只保留有效部分，其下由齿根圆弧过渡。
- “齿根圆弧半径”填 0 表示自动计算：按小径与两侧齿面精确相切求半径（本默认参数算得 R1.820，落在图纸允许的 R1.8~2 内；相切点约 Ø163.378，保证覆盖起始圆 Ø163.540）。
- 齿根圆弧同时与两侧渐开线齿面相切，底部最低点落在小径上，轮廓连续；若指定半径使相切点高于起始圆，程序会自动限制为起始圆处的最大可用半径，避免缩短有效渐开线。

## 重新编译

修改源码后双击 `build.cmd` 即可重新编译（需本机装有 AutoCAD 2024，默认路径 `D:\AutoCAD 2024`；路径不同请修改 `build.cmd` 中的 `ACD`）。

## 已知限制

- 仅支持外花键；内花键（花键孔）暂未实现。
- 生成的轮廓是二维平面图，无 3D。
